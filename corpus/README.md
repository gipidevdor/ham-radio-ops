# Semantic corpus

Original synthetic transcripts, not recordings of actual radio activity.
The independent expected outcomes in `semantic.json` include partial identity,
unsupported free text, explicit reports and invalid numeric reports. Tests compare
them directly with Message parsing. Corpus content uses Artistic License 2.0.
The full-session original fixture is in [examples](../examples/complete-it-cw.jsonl).
No example is presented as a universal mandatory QSO script.
