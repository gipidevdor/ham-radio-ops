# Security reports

Report suspected vulnerabilities privately to the repository owner using GitHub
private vulnerability reporting if enabled. Do not publish credentials, personal
station details or a working exploit in a public issue. The project is currently
a development version; no supported stable release has been published.

Unknown or ambiguous text is ordinary input, not executable instructions. Keep
observation metadata truthful and use output directories protected against other
writers. See [architecture](docs/architecture.md) for file replacement boundaries
and [dependency review](docs/dependency-audit.md) for audit limitations.
